# 测试报告

## 测试环境

- 开发板：STM32F103C8T6
- 烧录器：DAPLink（SWD）

- OLED：0.96 寸 I2C，地址 0x78
- 固件版本：V1.0.0

## 测试结论

所有基础题和提高题功能**全部通过**。系统稳定，无死机、无丢命令、无状态错乱；OLED 断开时按键、LED、串口不受影响（已实现通信降级）。

## 已知问题

- 快速闪烁与固定闪烁共用同一个周期变量，用户执行 `SET PERIOD` 后两种模式节拍一致（模式作为预置档位，周期可被细调）。
- 流水灯效果未实现（作为加分项，非必需）。

## 未覆盖项

- 长时间连续运行（>24h）稳定性未测试。
- 环形缓冲区溢出场景未构造（未触发过溢出）。
- 不同供电电压/温度环境下的可靠性未测试。
