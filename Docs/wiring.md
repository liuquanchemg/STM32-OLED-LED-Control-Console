# 硬件接线说明

## 器材清单

| 器材                 | 数量 | 说明         |
| -------------------- | ---- | ------------ |
| STM32F103C8T6 开发板 | 1    | 核心控制板   |
| DAPLink 烧录器       | 1    | 下载和调试   |
| 0.96 寸 OLED 屏幕    | 1    | I2C 接口     |
| CH340 串口模块       | 1    | 串口通信     |
| 面包板               | 1    | 布线用       |
| 杜邦线               | 若干 | 连接         |
| 外接 LED             | 1    | 低电平点亮   |
| 独立按键             | 3    | 用于菜单操作 |

## DAPLink 接线

| DAPLink | STM32F103C8T6 |
| ------- | ------------- |
| SWDIO   | PA13          |
| SWCLK   | PA14          |
| GND     | GND           |
| 3.3V    | 3.3V          |

**注意事项**：
- PA13 / PA14 是 SWD 调试引脚，配置为 Serial Wire Debug，不得改作普通 GPIO。
- DAPLink 用于下载、调试和供电，必须与开发板共地。

## CH340 串口接线

| CH340 | STM32F103C8T6   |
| ----- | --------------- |
| TXD   | PA3 (USART2_RX) |
| RXD   | PA2 (USART2_TX) |
| GND   | GND             |
| VCC   | **不接**        |

**注意事项**：
- CH340 的 TXD 必须接 STM32 的 RX，RXD 必须接 STM32 的 TX。
- CH340 的 VCC **不接**，由 DAPLink 给板子供电，避免电源倒灌。
- 串口参数：**115200-8-N-1**。

## OLED 接线

| OLED I2C | STM32F103C8T6 |
| -------- | ------------- |
| VCC      | 3.3V          |
| GND      | GND           |
| SCL      | PB6           |
| SDA      | PB7           |

**注意事项**：
- OLED 设备地址为 `0x78`（部分 1.3 寸模块为 `0x7A`，需修改 `oled.c` 中的 `OLED_ADDRESS`）。
- I2C 总线需要上拉电阻（多数 OLED 模块自带上拉）。

## 按键接线

| 按键 | STM32F103C8T6 | 功能                         |
| ---- | ------------- | ---------------------------- |
| KEY1 | PB13          | 光标移动 / 长按切换 LED 模式 |
| KEY2 | PB14          | 确认 / 翻转 LED / 调整参数   |
| KEY3 | PB15          | 返回 / 退出                  |

**注意事项**：
- 按键一端接 GPIO，另一端接 GND。
- GPIO 配置为**上拉输入**（`GPIO_PULLUP`），按下时读数为 0。

## 外接 LED 接线

| LED  | STM32F103C8T6        |
| ---- | -------------------- |
| 负极 | PA6                  |
| 正极 | 3.3V（串联限流电阻） |

**注意事项**：
- **低电平点亮**：`GPIO_PIN_RESET` 点亮，`GPIO_PIN_SET` 熄灭。
- 有效电平统一封装在 `BSP/bsp_led.c`。
- 不要将裸 LED 直接接到 GPIO，必须串联限流电阻（通常 220Ω ~ 1KΩ）。

## 引脚分配总表

| 引脚 | 功能      | 备注         |
| ---- | --------- | ------------ |
| PA2  | USART2_TX | 接 CH340 RXD |
| PA3  | USART2_RX | 接 CH340 TXD |
| PA6  | LED 输出  | 低电平点亮   |
| PA13 | SWDIO     | 调试用       |
| PA14 | SWCLK     | 调试用       |
| PB6  | I2C1_SCL  | OLED SCL     |
| PB7  | I2C1_SDA  | OLED SDA     |
| PB13 | KEY1      | 上拉输入     |
| PB14 | KEY2      | 上拉输入     |
| PB15 | KEY3      | 上拉输入     |

## 上电检查清单

- [ ] DAPLink 与开发板共地
- [ ] CH340 的 VCC 未连接
- [ ] OLED 的 VCC 接 3.3V（不是 5V）
- [ ] 按键另一端接 GND（不是 VCC）
- [ ] LED 串联了限流电阻
- [ ] 所有模块共地
